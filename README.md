# Falling Type Tool

一个可离线运行的单文件文字掉落动画工具。

## 使用方法

1. 下载 `index.html`。
2. 使用支持 Canvas MediaRecorder 与 H.264/MP4 编码的新版浏览器打开。
3. 调整画布、屋顶、文字、图案和运动参数。
4. 导出 PNG，或录制完整掉落过程并导出 MP4。

## 功能

- 可调屋顶边长、角度、尺寸和颜色
- 每个输入词至少掉落一次，并加入 20 个随机几何图案
- 胶囊形碰撞、堆叠摩擦和静止休眠
- 自动录制至全部物体掉落稳定
- PNG 与 MP4 导出

所有代码均包含在 `index.html` 中，不需要安装依赖或启动服务器。
